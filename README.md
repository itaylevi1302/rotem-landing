# דף נחיתה – רותם סגל

דף נחיתה לקמפיין Google Ads. נפרד מהמדריך הדיגיטלי (rotem-guide), עם אותו עיצוב.

## לפני שמעלים לאוויר
1. **דומיין:** להחליף את `https://itaylevi1302.github.io/rotem-landing/` בכתובת האמיתית ב־`index.html`, `robots.txt` ו־`sitemap.xml`.
2. **Google Ads:** בתוך `index.html`, בבלוק "הגדרות מעקב", למלא את `GADS_ID` (למשל `AW-123456789`) ואת `GADS_LEAD` (תווית ההמרה).
   לחיצה על וואטסאפ או על טלפון נספרת כהמרה. לחיצה על המדריך החינמי לא נספרת.
3. **אושר על ידי רותם:** שיחת היכרות של 15 דקות בלי עלות. **עוד לאשר:** תשובות השאלות הנפוצות ונוסח מדיניות הפרטיות.
4. **המלצות:** בסקשן `#reviews`. להוספת המלצה, להעתיק בלוק `<figure>`.
